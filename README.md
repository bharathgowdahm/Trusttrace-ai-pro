
# TRUSTLENS AI

### Buy Smart. Verify Before You Trust.

TrustLens AI is an AI-assisted second-hand smartphone
investigation platform.

## Core capabilities

- Visual product consistency analysis
- IMEI and serial format validation
- Used smartphone price intelligence
- Scam-pattern detection
- Evidence-based seller risk signals
- Explainable TrustScore
- Investigation reports

## Technology

- Python 3.12
- FastAPI
- React
- Tailwind CSS
- Vercel
- Supabase
- OpenCV
- Pillow

## Project status

Currently under development.

## Important

TrustLens AI provides investigative signals,
not guaranteed authenticity certification.

A valid serial format does not prove ownership,
genuine hardware, or a clean device history.
